# Holiday Countdown + Edit UX Polish

## Report

## [S1] Problem

1. 编辑页提醒时刻有 4 个预设（08:00/09:00/12:00/20:00），用户只要 8:00 / 12:00 / 20:00 + 自定义；自定义需弹出时间选择器。
2. 「重复」开启后的间隔步进与单位 Chip 分两行、外框过高，编辑表单显得臃肿。
3. 用户希望在首页看到「距离下一次法定假日还有多久」：放假首日倒数、假日名动态展示；普通周末不当作法定假日，但若放假首日落在周末仍以该日为目标。

## [S2] Design

### 2.1 提醒时刻精简 + 自定义

| 契约 | 行为 |
|---|---|
| 预设 Chip | **08:00 / 12:00 / 20:00 / 自定义**（仅 `remindOn` 时显示） |
| 自定义 | 点「自定义」打开 Material3 `TimePickerDialog`；确认后写入 `remindHour`/`remindMinute` |
| Chip 选中态 | hour/minute 命中预设则选中对应预设；否则选中「自定义」，Chip 文案显示当前 `HH:mm` |
| 旧数据 | 落库字段不变（`remindHour`/`remindMinute`）；09:00 等非预设值打开时自动表现为「自定义 · 09:00」 |
| 默认 | 新事件仍 09:00 → 首次显示为自定义 09:00；或默认改为 08:00（推荐改为 **08:00**，与预设第一档对齐） |
| 取消 | TimePicker 取消不修改时刻 |
| 详情/调度 | 不变：继续读 `remindHour`/`remindMinute` |

### 2.2 重复模块紧凑布局

| 契约 | 行为 |
|---|---|
| 布局 | 开启重复后 **单行**：`每` + 间隔 `[− n +]` + 单位 Chip（天/周/月/年） |
| 外框 | 去掉大块 `surfaceVariant` 圆角盒；仅保留轻量间距（约 8.dp 上下） |
| 交互 | 间隔 1..999 与单位选择逻辑不变 |
| 关闭态 | 仍只显示「重复」+ Switch 一行 |

### 2.3 法定假日倒数（内置表）

| 契约 | 行为 |
|---|---|
| 数据 | 内置 **2026 年** 国务院放假调休安排（国办发明电〔2025〕7 号）；按放假区间建模 |
| 目标日 | 每个假日的 **放假第一天**（含落在周六/周日的首日） |
| 不含周末 | 普通周末不作为假日目标；不把非放假的周末算进倒数目标集合 |
| 倒数 | 自然日：`ChronoUnit.DAYS.between(today, start)`；今天即放假首日 → 0 |
| 假日名 | 动态展示当前目标假日名（元旦/春节/清明节/劳动节/端午节/中秋节/国庆节） |
| 假期中 | 若今天落在某放假区间内：状态 `ONGOING`，文案「{name} · 假期中」，不倒数到本段首日 |
| 跨年 | 只内置 2026；若今天晚于表内最后假日且无后续年数据，隐藏假日卡/轮播页 |
| 展示 A | 首页列表上方 **独立小卡**：假日名 + 倒数数字（底色/描边与普通列表区分） |
| 展示 B | 首页 **轮播** 追加一页假日卡；底色高亮区分于用户纪念日卡 |
| 空态 | 首页无用户事件时，假日小卡仍可见（不依赖 events 列表） |
| 测试 | 纯函数单测：下一段假、假期中、放假首日为周末、表尾无数据 |

#### 2026 放假区间（来源：中国政府网）

| 假日 | 放假区间 | 天数 |
|---|---|---|
| 元旦 | 2026-01-01 ~ 2026-01-03 | 3 |
| 春节 | 2026-02-15 ~ 2026-02-23 | 9 |
| 清明节 | 2026-04-04 ~ 2026-04-06 | 3 |
| 劳动节 | 2026-05-01 ~ 2026-05-05 | 5 |
| 端午节 | 2026-06-19 ~ 2026-06-21 | 3 |
| 中秋节 | 2026-09-25 ~ 2026-09-27 | 3 |
| 国庆节 | 2026-10-01 ~ 2026-10-07 | 7 |

调休补班日（2/14、2/28、5/9、9/20、10/10）不作放假区间，不参与倒数目标。

## [S3] Out of Scope

- 提醒音效、按事件不同重复时刻策略
- 调休补班日展示
